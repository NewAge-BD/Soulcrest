# AION2 event icons

Three unchanged game symbols supplied by the user on 2026-10-18, plus the prepared Dimensional
Invasion screenshot icon described below. Game artwork © NCSOFT; no open artwork license is claimed.
These files are bundled locally; there is no runtime download.

Spacetime Rift uses the supplied 128 x 128 world-map symbol (`spacetime-rift-worldmap.png`).
Shugo Festival uses the supplied 72 x 72 original ESC-menu FieldEvent sprite
(`shugo-festival-esc-menu-original.png`). Both replace the former Content Navigator variants
at the user's request. Artifact Siege retains its 64 x 64 Content Navigator variant from the
original Abyss Artifact content family, not a separately verified Siege popup variant. These
three symbols retain their original bytes.

Dimensional Invasion was replaced at the user's request on 2026-10-18 with the gold/orange
medallion from a supplied 60 x 57 screenshot. Background extraction and cleanup/upscaling
used the built-in Imagegen editor; the 1254 x 1254 RGBA PNG retains genuine alpha and is
rendered into the existing icon bounds. It is a prepared derivative of the screenshot, not
an unchanged original symbol. The former Content Navigator symbol is no longer used.
Source screenshot SHA-256: `13ea2f9de14798c49c3f89aa5bd73ed2fdc878b27a5be274d3e9a9e8397fbbcd`.
